# 严格 PAC 扩展

可选的 Chromium 扩展，只在用户点击启用后修改当前浏览器的代理设置，不改系统网络。
它设置 `mandatory: true`：PAC 无法下载或内容无效时，浏览器应失败而非自动直连。

1. 先启动 gp-proxy，确认本机 `http://127.0.0.1:8080/proxy.pac` 可用。
2. 打开 `chrome://extensions`（Edge 使用 `edge://extensions`），启用开发者模式。
3. 选择“加载已解压的扩展程序”，选中本目录。
4. 打开扩展弹窗，确认 PAC 地址，点击“启用严格 PAC”。仅接受明确端口的 loopback 地址。
5. 企业规则变更后点击“刷新规则”，关闭旧连接，再核对目标行为。
6. 停用时点击“停用并恢复原设置”，移除本扩展的设置，恢复浏览器下层配置。

扩展只申请 `proxy` 权限，不存储密码、Cookie 或浏览记录。它不补全未知企业域名，
也不撤销已经开始的连接；未列入 PAC 的目标仍可能直连。隐私窗口、浏览器重启后
的持久性及企业策略冲突未作全面验证。其他扩展或管理员策略控制代理时可能无法启用。
